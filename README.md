# Coin Catcher

Проект создан с использованием Java 21 и фреймворка [libGDX](https://libgdx.com/)

**Coin Catcher** - игра, по задумке которой игрок должен зарабатывать очки, путем собра монет.
## Игровая механика:
- Игрок управляет зелёным квадратом клавишами `A`/`D` или стрелками.
- При нажатии `Shift` игрок может ускориться.
- Сверху падают жёлтые монеты и красные препятствия.
- За каждую пойманную монету начисляется 10 очков.
- При столкновении с препятствием теряется одна жизнь.
- После потери трёх жизней игра заканчивается.
- Клавиша R запускает новую игру.

## Обновление
Игра была разбита на окна, теперь имеются базовые окна:
* Menu - стартовое окно
* Play - игровое окно, непостредственно с игрой
* Settings - окно настроек, на данны момент можно настроить `VSync` в On/Off, настройка звука `Volume`. Настройки сохраняются при перезапуске игры.
* GameOver - окно при поражении, предлагает начать новую игру или закончить полностью.

Реализована остановка игры клавишей `Esc`
